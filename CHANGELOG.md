# Changelog

## 1.0.0

- Add character summaries, saved inventories, equipment, mail, auctions and guild bank tabs.
- Record professions and recipes, quests, reputations, talent groups, spells, companions, currencies, achievements and raid lockouts.
- Search possessions and the observed item catalog, including server-specific custom items.
- Preserve full item links and keep item metadata separate for each realm.
- Add item ownership tooltips, equipment comparisons and higher-item-level searches.
- Allow account transfers after a manual request and approval.
- Add automatic in-game update notices and a movable minimap button.
